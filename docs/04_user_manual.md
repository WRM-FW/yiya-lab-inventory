# 义牙实验室物资与耗材管理系统 - 实验室成员与管理员使用手册

欢迎使用**义牙实验室物资与耗材管理系统**！本系统专为工程实践、材料研究、3D 打印加工、电路焊接及学生科创竞赛量身定制。为了保障实验室物资台账准确可靠，请仔细阅读本使用指南。

---

## 一、账号注册与准入审核流程

### 1.1 成员注册申请
1. 访问实验室系统主页，点击 **“提交注册申请”**。
2. 填写**真实姓名**、**学号/工号**、常用**邮箱**以及设置密码。
3. 提交后，系统将自动跳转至 **“待审核状态页面”**。
4. **安全提示**：新注册账号默认处于待审核状态，在此期间无法查看任何物资库存或办理工具借还，请主动联系实验室管理员（指导教师或实验员）进行资质审核。

### 1.2 管理员审核批准
1. 管理员登录后，点击顶部导航栏的 **【🛡️ 审核与人员】**。
2. 在 **“待审核新成员申请”** 列表中，核对申请人实名信息与学号。
3. 点击 **“✅ 准入为普通成员”**，该申请人即刻获得系统全部物资查询、消耗登记与借还权限。

## 二、3D 打印耗材管理使用指引 (核心业务)

### 2.1 理解规格与剩余重量
- **采购包装规格**：如 `1 kg/卷`、`500 g/盘`，代表原材料出厂时的标准规格。
- **当前在库总重量**：以**克 (g)**为标准存储单位记录当前该规格材料剩余的总净重。系统界面会自动提供千克（kg）辅助换算（例如：`3,250 g (3.25 kg)`）。
- **材料独立建档**：不同材质（PLA / PETG / ABS / TPU / PC）、不同品牌（Bambu Lab / eSUN）、不同颜色（哑光白 / 纯黑）及不同线径（1.75mm）必须独立建立档案，避免不可互换材料混算。

### 2.2 打印消耗登记规范
1. 完成 3D 打印或模型切片后，在 **【🧵 3D耗材】** 列表中找到对应线材。
2. 点击 **“消耗扣减”**（或进入 **【⚡ 出入库】** 页面）。
3. 选择变更类型为 **“领用/打印消耗”**。
4. **单位自由换算**：
   - 习惯使用克（g）的同学可直接输入模型重量（例如：`250 g`）。
   - 若使用整卷扣减，可选择千克（kg）并输入 `1 kg`，系统将自动精确换算为 `1,000 g` 进行扣减。
5. 填写用途说明（例如：“智能车底盘电机固定座打印消耗”），点击提交。

### 2.3 补充采购入库与实物盘点
- **新耗材入库**：点击对应耗材的“入库增加”，输入采购到货的实际克数或千克数。
- **实物盘点与校准**：若发现线材受潮烘干后重量变化或长期累积误差，可选择“实物盘点重置”，输入当前电子秤实称总重量，系统将自动平账并留下审计说明。

## 三、通用工程消耗品管理指引

### 3.1 稳定计量单位原则
- 通用消耗品（焊锡丝、松香助焊膏、洗板水、热缩管、紧固件螺丝等）各自拥有固定的计量单位（如：卷、盒、瓶、包、件、支）。
- 严禁对不同单位的物资进行数值相加或相互抵扣。已建档物资的计量单位保持稳定。

### 3.2 领用与报损
1. 制作电路板或装配机械结构需要领用消耗品时，进入 **【📦 通用耗材】** 页面。
2. 找到目标消耗品，点击 **“领用扣减”**。
3. 输入领用数量并备注使用工位或赛事组别，系统将自动更新在库数。
4. 若出现助焊剂挥发变质或耗材遗失损坏，请选择 **“报损与损坏处置”** 并注明原因。

## 四、可重复使用工具与借还管理指引

### 4.1 数量守恒机制
系统采用池化数量守恒机制：
$$\text{工具总购置数} = \text{在库可用数} + \text{当前借出数}$$
当在库可用数为 0 时，系统将自动锁定该工具，禁止重复超借。

### 4.2 办理工具借出
1. 在 **【🔧 工具借还】** 页面，找到所需仪器（如：T12 数显烙铁、数字万用表、游标卡尺）。
2. 点击 **“办理借用”**。
3. 确认借出数量（默认 1 件），核对借用人姓名，并填写联系电话及预计归还日期。
4. 提交后，工具可用数立即扣减，当前借出数累加，并生成一条外借单据。

### 4.3 办理工具归还核销
1. 实验或加工结束后，将工具归还至指定工位或收纳柜。
2. 登录系统，进入 **【🔧 工具借还】** -> **【⏳ 当前借出中单据】** 选项卡（或首页的监控看板）。
3. 找到对应的借出记录，点击 **“核销归还”**。
4. 填写验收情况（如：“配件齐全，正常归还”），点击确认。
5. 系统立即释放借用额度，在库可用数恢复，借还单据归档至历史记录。

## 五、库存操作流水与台账导出

1. 点击顶部导航栏的 **【📜 审计流水】**。
2. 查看实验室内所有 3D 耗材、消耗品及工具的历史流转明细。
3. 支持按物资大类、操作类型（入库/消耗/报损/盘点/调整）及操作人员进行多重过滤。
4. **期末导出**：学期末或科创竞赛结项时，点击右上角 **“📥 导出 Excel / CSV 流水台账”**，即可将全量明细下载为标准表格，用于实验室资产年检与采购总结。

## 六、移动端与现场操作贴士

- 系统针对手机屏幕进行了专门的响应式优化，支持在手机浏览器中直接使用。
- 建议成员在 3D 打印机旁或焊接工位前，通过手机快速搜索物资、查看剩余在库重量、登记扣减或办理借还，告别纸质登记册丢失与记账遗漏问题。
